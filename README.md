# IITK-Project
Daily Expense Tracker
Personal Expense Tracker
A simple, Python-based CLI application to help you log daily expenses, set a monthly budget, and track your spending habits. 
🚀 Features
Add Expenses: Log date, category, amount, and description for every purchase.
View History: See a formatted list of all recorded expenses.
Budget Management: Set a total monthly budget and instantly see your remaining balance.
Persistent Storage: Automatically saves and loads your data from an expenses.csv file so you never lose your records.
Error Handling: Robust validation to prevent crashes from invalid numerical inputs or corrupted data files.

📖 Usage Guide
When you run the program, you will see the Expense Tracker Menu:
Add expense: Follow the prompts to enter the date (YYYY-MM-DD), category, amount, and a brief note. 
View expenses: Display all saved transactions in a clean table format. 
Set and Track budget:
Press S to set your total monthly budget.
Press T to see your total spent vs. what's remaining.
Save expenses: Manually export your current session to the CSV file.
Exit: Saves your data automatically and closes the application.
